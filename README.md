# BuyFromOc — OCHub Marketplace

E-commerce marketplace by **OC Gadgets** (RC 1847392).

## Pages
- `index.html` — Main marketplace (BuyFromOc)
- `seller-portal.html` — Seller product submission portal
- `admin-dashboard.html` — Admin review & management console

## Admin Access
- URL: `/admin-dashboard.html`
- Demo password: `ocadmin`

## Tech
- HTML5 · Tailwind CSS (CDN) · Alpine.js (CDN) · Lucide Icons
- Storage: browser `localStorage` (demo mode)

## Links

- Admin console → reviews & approves submissions
